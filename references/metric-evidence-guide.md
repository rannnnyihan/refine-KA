# 23维充分证据要求

每项均需同主体、事实所属期、具体事实、档位理由及原始页面/报告位置；不能只有分数或一句总结。优先当年S1，其次当年S2/S3，再回退去年。表中说明“足以判断什么”，不要求为凑篇数重复检索。

| 指标 | 必须说明的信息 |
|---|---|
| 营收增长 | 营收单位币种、当期与可比期、增长值和计算；合并集团还是目标公司 |
| CAPEX增长 | 现金流或资本开支定义、当期/基数、同比；项目总投资不能冒充当期支出 |
| 研发投入增长 | 研发费用或总投入的明确口径、两期值或直接披露同比、计算 |
| 客户预算信号 | 哪类/哪个客户、采购订单或预算事件、时间、金额或规模依据、是否已落实 |
| 赛道增长 | 细分市场定义、地区范围、统计期间、增长率、机构口径及企业适用性 |
| 市场份额/排名 | 市场边界、年份、排名/份额数值及发布者方法；“领先”不等于Top3 |
| 出口增长 | 海关出口/境外收入二者区别、可比区间与增速，不拿境外占比变化当出口同比 |
| 客户结构 | 主要客户或客户类型、行业覆盖、集中度/稳定性证据；不凭logo推采购关系 |
| 融资 | 日期、轮次/方式、金额、投资方、完成或拟议状态 |
| 产能扩张 | 具体项目、投资/产能规模、地点、签约/在建/投产阶段及更新时间 |
| 海外投资 | 国家、投资主体、项目、金额或规模、实际进展 |
| 并购 | 买卖双方、标的、交易时间、规模及完成状态；意向不是交割 |
| 招聘人数增长 | 招聘人数/岗位数量的明确定义、同平台同周期可比基数；员工人数非招聘人数 |
| 关键岗位 | 岗位名称、职能、招聘日期/有效状态及与评分类别的对应 |
| 组织扩张 | 新设组织/团队/事业部等具体事件、时间、范围及实施状态 |
| 研发强度 | 研发费用/投入与营收的同主体同期间定义、占比及计算或正式披露占比 |
| 技术突破 | 具体技术、解决的问题、可检验性能/认证/试验、所处阶段及时间 |
| 新品发布 | 产品名称、用途、发布日期、发布/试制/上市状态 |
| 商业化成熟度 | 产品与客户应用、试点/量产/规模销售阶段、交付/订单或收入证据 |
| 国家级资质 | 资质全称、授予机关、批次/年份、目标主体与有效性 |
| 荣誉榜单 | 榜单名称、颁发机构、年份/名次、目标主体；行业与地方榜区分 |
| 绿色认证 | 认证/名单全称、认证对象（公司或工厂）、机构、日期与有效期 |
| 政策扶持 | 政策/项目名称、主管机构、批准/到账/公示阶段、金额或支持形式与年份 |

具体数值未披露可用足以支持原档位的事实，但不可虚构金额、客户名或日期。数值阈值档位必须有数值。对评分表本来就是定性的档位，允许measurement.method=qualitative：CAPEX“基本稳定/明显缩减投资”、招聘的三个已证实档位、赛道“成熟行业/衰退行业”。需basis、calculation（正式结论与判定路径）及status_context，不能填假0%或把“查不到”当定性例外；其他数值档位不接受这个例外。

每个最终选用期填写detail（见data-schema）。首次获取证据时即可记录；初筛发现的简单线索进入精采后必须深化为可审读信息。分数高不代表信息完整，信息长也不代表依据充分。
