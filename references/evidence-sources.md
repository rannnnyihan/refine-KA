# 来源等级与系数


S1：企业年报、正式公告、官网一手披露、股东年报中明确属于该主体的数据。
S2：政府、监管原始名单、资质、项目、资金、环评和备案。
S3：有发布机构、明确口径的行业协会、研究报告、专业第三方。
S4：一般转载、聚合、出处不完整的线索。保留系数供来源说明及旧数据识别，新版禁止S4定档，usable=false；通过实际追溯找到S1–S3后用原始来源定档。

选择顺序为当年S1、当年S2、当年S3、去年S1、去年S2、去年S3。比较事实所属年份，不比较文章发布日期。先读最新年报与官网是采证入口策略，不赋予去年年报数据压过当年S2的权利。

同期同一事实的独立充分证据组取最高可信组，组内必要来源取最低系数：max(min(各组必需来源系数))。多篇转载不重复加分，弱来源不会拉低另一组独立足够的强证据。冲突先处理，不能机械择高等级忽略反证。

原始档位分乘所选系数；完成检索仍未知才领取评分表缺省分，缺省不乘系数也不计证据覆盖。原分值与来源系数尚非经验校准的企业实力模型。
