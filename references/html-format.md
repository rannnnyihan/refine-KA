# 最终结果界面

单个UTF-8 HTML，CSS/JS内嵌，可离线打开。沿用gen_company_html.py的深绿标题、白色卡片、主表和右侧详情抽屉。无需新建视觉体系。

## 展示范围
只展示最终Top30及其23维事实、评分标准与来源解释。**不展示粗排分数、筛选通道、200家输入名单、40家精采名单、10家备选或落选表，不用折叠面板或隐藏JSON夹带。** 内部过程数据留运行目录，不发送至页面。

主表：排名、企业、6组分数、总分、简短摘要、证据数、信息可信度。保留搜索、组权重调节和详情抽屉；权重滑杆是这30家内部的情景排序，明确不会重新筛选全候选池。默认显示最终规则排名。

## 23维详情
每维完整展示选用期、具体事实、主体/业务范围、实际期间、数值与单位/事件状态、定档原因、计算依据、来源位置、发布日与抓取日、来源系数、局限。事实和来源摘录不为排版截断；摘要可短，详情必须能核查。历史回退显式说明，三期用于追溯，不伪装所有年份均有信息。

顶部显示当前30家的当年证据覆盖、历史回退、S1证据比例与完整度。只展示与当前30家有关的限制，不把内部预筛告警或其他公司姓名输出给用户。来源链接必须具体页面，http/https且安全转义。

## 完成与草稿
生成器先重新计算，再检查690项信息；缺省、未定档、主体/时期/数值口径或状态描述缺失都不能作为完成版交付。

**生成的所有HTML都不得出现「【未完成草稿】」字样**（标题水印已永久移除，见 `gen_company_html.py`）。但页面内的真实状态说明必须保留：顶部"证据覆盖/完整度"指标、`method` 行的 `状态：provisional` 与"信息完整度验收未完成，请查看各维度标注"等诚实边界文字**不可删除**——它们区分的是"阶段性结论"而非"完成版伪造"。未通过验收时生成器仍拒绝输出完成版，须显式 `--draft` 才能生成内部预览。

完整度检查只是结构与部分公式校验，执行智能体必须逐项核对原文。公开证据支持的业务优先级不等同企业真实实力，维持这条简短说明。CSS/JS无外部依赖，避免外部文本成为HTML或脚本。

> 注意：重新生成HTML会**冲掉手动注入的DOM**（如公司名下的"细分赛道""股票代码/未上市"小字、被删副标题）。凡在HTML做过手工增量，重生成后必须重跑注入脚本恢复。
